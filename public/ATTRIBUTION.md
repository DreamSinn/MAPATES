# Atribuição de mapa e dados

O Skyrim Atlas reutiliza os tiles de mapa e as coordenadas de locais disponibilizados por [skyrimmap.com](https://skyrimmap.com), adaptados de [UESP](https://en.uesp.net/wiki/Skyrim:Skyrim), sob a licença [Creative Commons Attribution-ShareAlike 2.5](https://creativecommons.org/licenses/by-sa/2.5/).

A atribuição deve permanecer visível no produto: **Map tiles © UESP (uesp.net), CC BY-SA 2.5 · Adaptados via skyrimmap.com**.

Este projeto não reutiliza a marca, o logotipo, o código, os ícones ou a identidade visual do skyrimmap.com. O Skyrim Atlas usa uma interface própria. Adaptações dos dados e tiles licenciados devem permanecer sob CC BY-SA 2.5, com esta atribuição.
